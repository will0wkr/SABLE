# 암호학이 필요한 이유

스마트폰과 컴퓨터 사용이 일상이 된 오늘날에는 개인 정보와 같은 중요한 데이터를 안전하게 다뤄야 할 필요가 매우 커졌다. 암호학은 제 3자가 나의 데이터를 함부로 읽거나 바꾸지 못하게 하는 기술로 현대 사회의 핵심적인 역할이 되었다. 
우리가 주로 사용하는 삼성에서는 기기가 변조되면 삼성 페이 같이 민감한 기능의 접근을 막는 기능이 있으며, SK 텔레콤을 비롯한 통신사들에서 사용자 인증 값들이 유출되며 논란이 되었다. 이러한 일들은 큰 피해로 이어질 수 있기 때문에 암호학을 통해서 위와 같은 상황을 방지해야 한다.
결국 디지털 사회에서 암호학이 가지는 의미는 단순히 이론, 학문적인 것이 아니라 실제 사회 전반의 기반이 되어야 한다는 것을 알 수 있다.

# 기밀성, 무결성, 인증, 부인 방지
## 1. 기밀성
- 기밀성은 허가된 사람만 내용을 볼 수 있게 하는 것으로.
- 인터넷에서 볼 수 있는 나의 개인 정보나 카카오톡 대화 내용 등이 이에 해당한다.

## 2. 무결성
- 무결성은 정보가 중간에 바뀌지 않았음을 보장하는 것으로.
- 10만 원 송금 시 해당 금액이 10원, 100만 원이 되거나
- 내가 업로드한 파일이 중간에 변조되지 않도록 지켜주는 역할이다.

## 3. 인증
- 인증은 현재 서비스에 접속해 요청하는 사람이 본인이 맞는지 확인하는 것으로.
- 아이폰 사용자들의 Face ID, 사이트 로그인, 문자 인증, OTP 등이 이에 해당한다.

## 4. 부인 방지
- 부인 방지는 특정 행위에 대한 증거를 남겨 부정할 수 없게 하는 것이다.
- 예를 들어 전자서명이나 은행 이체 기록처럼 행위에 대한 책임을 남기는 역할.

## 5. 종합
- 종합적으로 위 4가지 개념은 독립되어 사용하기 보단 기밀성이 보장된 시스템을 이용할 때 인증을 통해 접속하고, 이용한 내용의 무결성을 보장하면서 부인 방지를 위한 증거를 남기는 형식이다.
- 일상 속 예시를 들면 인터넷 뱅킹을 이용해 친구에게 3만 원을 입금하는 상황이라면.
- 1. 비밀 번호/지문/OTP를 이용해 사용자 확인.
- 2. 송금할 때 이용하는 정보 (계좌번호, 잔액, 비밀번호 등) → 타인에게 공개 X (이를 위해 전송되는 데이터는 암호화됨.)
- 3. 보낸 금액인 3만 원이 3원, 30만 원 등으로 변조되거나 다른 계좌로 들어가면 안 되기에 내용이 변조되지 않았는지 확인.
- 4. 로그인 기록, 인증 기록, 송금 요청 기록, 전자서명 등의 기록을 남겨 사용자가 서비스 사용을 부정할 수 없게 함.

# 평문, 암호화, 키
## 1. 평문
- 평문은 우리가 접하는 일반적인 글이다.
- 이 글 또한 평문으로 이루어진 글이며, 만일 민감 정보가 포함되어 있다면 정보가 노출됐을 때 문제가 발생할 수 있다.

## 2. 암호화
- 따라서 민감한 정보를 다룰 때 일정한 규칙에 따라 다른 형태로 변환해 겉으로 봐서는 무슨 뜻인지 파악하지 못하게 한다.
- 즉, 정보를 숨기기 위해 변환하는 것이 암호화의 본질.

##  3. 키
- 키는 암호화가 실제로 작동할 수 있게 하는 핵심 값으로 복호화에 이용된다.
- 따라서 원본 파일의 복구는 어떤 키를 쓰느냐에 달렸으며,
- 케르크호프스의 원리(Kerckhoffs's Principle) : "키를 제외한 시스템의 모든 내용이 알려지더라도 암호체계가 안전해야 한다."에서 말하는 것처럼 실제로 현대 암호학 체계에선 알고리즘을 지키기보단 키를 관리하는 것이 더 중요하다.
