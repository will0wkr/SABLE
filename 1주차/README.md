# 개요
- 해당 폴더의 내용은 2026.04.17에 진행되는 보안 스터디 소나기 암호학 트랙, SONAGI:SABLE의 과제 내용을 담는다.
- 과제는 자료 조사, 코드 구현, 퀴즈로 이루어지는데, 퀴즈는 17일에 공개되어 다음 과제 제출 때 동봉한다.
- 암호학을 배우기 위한 준비를 하며, 암호학의 세계에 입문한다.

# 과제 설명
## 노트
- `notes.md` : 자료 조사 내용
- 1주 차 주제는 다음과 같음.
- 1. 암호학이 필요한 이유
- 2. 기밀성, 무결성, 인증, 부인 방지
- 3. 평문, 암호화, 키

## 코드
- `codes/subject01.c` :  기밀성, 무결성, 인증, 부인 방지를 이해하기 위한 간이 뱅킹 시스템. 
- 인증을 통해 접속하면 사용자 정보(기밀성), 입력한 금액 입금(무결성), 입금 횟수 카운트(부인 방지)의 기능을 수행할 수 있다.
- `codes/subject02.c` : 평문, 암호화, 키를 공격자 입장에서 바라보기. 
- 공격자가 사용자의 전송을 중간에서 가로챘을 때 
- POV 1. 평문일 시 바로 그 내용을 알 수 있음.
- POV 2. 암호화된 값을 보고 바로 이해할 수 X.
- POV 3. 키를 통해 복호화한 상대는 사용자가 보낸 메시지를 온전히 이해할 수 있음.
