# 1주차 - 암호학 개요

## 학습 목표
암호학이 필요한 이유를 이해하고, 기밀성, 무결성, 인증, 부인방지의 개념을 익힌다.
또한 평문, 암호화, 키의 관계를 간단한 코드 예제로 확인한다.

## 학습 내용
- 암호학의 필요성
- 기밀성, 무결성, 인증, 부인방지
- 평문, 암호화, 키의 관계

## 구현 내용
- Subject01.c : 보안 속성을 간단한 은행 시나리오로 표현
- Subject02.c : 평문 전송과 암호화 전송의 차이를 단순 예제로 표현
