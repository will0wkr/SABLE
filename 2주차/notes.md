# 카이사르 암호

카이사르 암호는 알파벳을 일정한 칸 수만큼 밀어서 평문 문자를 암호문 문자로 바꾸는 방식이다. 
[1주 차 Subject02.c]()의 암호화 부분에서 **간이 암호화**라는 이름으로 다음 알고리즘을 사용하였다.
```c
for(int i = 0; i < len; i++){
        copied[i] += 1;
    }
```
이 코드도 글자를 1만큼 미룬다는 점에서 카이사르 암호화와 유사하다.
여기서 모든 글자에 같은 규칙을 적용하는 것이 핵심이다.

# 단순 치환 암호

단순 치환 암호는 a~z 전체를 다른 순서의 알파벳 표와 일대일로 대응시키는 방식이다. 
같은 평문 문자가 항상 같은 암호문 문자로 대응된다. 

# 키가 무엇을 바꾸는지

키는 알고리즘 내에서 실제 값을 어떻게 바꿀지 결정한다. 
같은 알고리즘이라도 키가 다르면 `will0w`가 `xjmm0x`가 될 수도 있고, `zloo0z`가 될 수도 있다.
(카이사르 암호는 알파벳에만 한정되기 때문에 0은 그대로 유지시켰다.)
카이사르 암호에서의 키는 몇 칸 밀 것인가가 되어 키가 `3`이면 `A → D`, `B → E`가 된다. 
단순 치환 암호에서도 대응되는 알파벳을 결정하기에 키는 암호화에 있어 핵심적이다.
