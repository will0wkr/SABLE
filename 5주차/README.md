# 1. 대칭키 암호란?
- 암호화에서 사용하는 키와 복호화에서 사용하는 키가 동일한 암호 방식.
- 키만 있으면 암·복호화가 모두 가능하기에 키를 안전하게 보관해야 함.
- 대표적인 대칭키 암호로는 AES, ChaCha20 등이 있음.

# 2. 대칭키 암호의 암·복호화
- 대칭키 암호화의 암호 흐름은 다음과 같음.
```math
C = E_k(P)
P = D_k(C)
```
- 복호화가 가능하기에 민감 정보 등을 다룬다면 암호화가 아닌 해시를 사용해야 한다는 점.
- 대칭키 암호는 크게 블록 암호와 스트림 암호로 나뉨.
## I. 블록 암호
- 데이터를 일정 크기의 블록으로 나누어 암호화하는 방식.
### AES 암호
- 평문 데이터를 128비트씩 잘라 각 블록을 AES가 내부적으로 만드는 키로 암호화.
- 해당 키를 **라운드 키**라고 칭하며, 사용자가 주는 키와 별도.
- 데이터가 130비트처럼 구성되어있다면, [128비트 데이터] + [2비트 데이터] + [126비트 패딩]으로 구성됨.
## II. 스트림 암호
- 데이터를 연속적인 흐름처럼 처리하며 암호화하는 방식. 
## ChaCha20
- 키 + nonce → 키스트림 생성.
- 암복호화 시 XOR 키스트림 사용. (XOR 두 번 하면 원상태)
- 단, 같은 키스트림을 재사용하면 안 됨.

# 대칭키 암호의 속도와 키 공유
- 대칭키 암호는 구조가 비교적 단순하고, 대량의 데이터를 처리하기 좋기 때문에 속도가 빠른 편.
- 동시에 키를 잘 지켜야 한다는 약점이 있음. 
- 따라서 키는 충분히 길어야 하며, 하드코딩 없이 사용해야 함.
- 또, IV나 nonce 값을 재사용하면 안 되며, 변조까진 막지 못하기에 신중한 사용이 야기됨.
