# 무차별 대입 공격 Brute-Force attack

## 개념
가능한 키를 전부 넣어보는 **전수 키 탐색**이자, 로그인 시 비밀번호 후보를 반복해서 넣어보는 비밀번호 추측 공격.

## 사용 이유
비밀번호가 예를 들어 숫자 4자리일 경우 특별한 부가 조치가 없다면 브루트 포스를 통해 쉽게 알아낼 수 있음.

## 실사용 예시
실제 웹 로그인에서 비밀 번호 후보를 넣어보거나, DB 탈취로 해시를 얻은 상태에서 후보 비밀번호를 해싱해 비교하는 오프라인 크래킹 등에 이용됨. 

## 방어기법
브루트포스는 후보 공간이 커질수록 비용이 폭발하기 때문에 현실에선 여러 겹의 방어로 막을 수 있음.
예를 들어 온라인에서는 rate limiting, account locking, CAPTCHA 등. 단일 계정에 대해 연속 실패 시도를 제한함.
오프라인 해시 크래킹 방어는 평문 저장 금지, 해시 단독 사용 금지 등.

# 빈도 분석
암호문에 등장하는 문자, 글자쌍, 패턴의 빈도를 세고, 자연어의 통계적 특징과 비교해 평문이나 키를 추정하는 방식.
단순 치환 암호나 카이사르 암호처럼 평문 문자와 암호문이 1:1 고정 대응되는 경우에 강함.

# 키 공간이 작다는 의미
**키 공간**이란? 가능한 모든 키의 집합.
키 공간이 작다는 건 공격자가 시도할 수 있는 범위가 작다는 것. 
따라서 아무리 암호화가 철저하더라도 키 공간이 적으면 공격 가능성이 높아짐.

# 종합
결국 키 공간이 작다는 의미는 브루트포스를 통해 쉽게 넘어갈 수 있다는 의미이며, 키 공간이 크더라도 암호문에 통계 패턴이 남으면 빈도 분석으로 공격 가능함.
따라서 방어자의 입장에서 키 공간을 충분히 크게 만들고, 브루트 포스 방지 장치와 암호문 패턴이 새지 않도록 해야 함.
