# 전자서명
```plain
전자 서명📝? 종이 문서에 자필로 하던 서명·도장 날인을 디지털 환경에서 대체하는 수단. 전자문서에 서명자의 신원과 서명 사실을 증명하는 전자적 형태의 정보이며, 종이 서명과 동일한 법적 효력을 가짐. ([전자서명법](https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=236201#0000))
```

## 전자서명의 3가지 요소
### 1. 인증
- `will0w`라는 인물이 서명한 문서가 정말 본인이 한 게 맞는지 확인해야 함.
### 2. 무결성
- 서명 이후 문서가 바뀐다면 모든 신뢰를 잃게 됨.
- 따라서 문서의 내용이 바뀌지 않도록 무결성을 보장해야 함.
### 3. 부인 방지
- 앞서 `will0w`라는 인물이 서명을 해놓고, 그 사실을 부인한다면 문제가 발생함.
- 일반적으로 이름을 이미지화하여 삽입한 서명은 복사하기 쉬워 부인 방지가 약하지만, 개인 키 기반 디지털 서명은 이러한 부분을 채워 줌.

## 관련 개념 정리
| 개념      | 역할                            |
| ------- | ----------------------------- |
| 비밀번호    | 사용자가 본인임을 증명하기 위한 지식 기반 인증 수단 |
| 해시      | 데이터를 고정 길이 값으로 압축해 변경 여부 확인   |
| salt    | 비밀번호 해시를 안전하게 저장하기 위한 랜덤값     |
| 무결성     | 데이터가 변조되지 않았음을 보장             |
| 인증      | 행위자가 누구인지 확인                  |
| 전자서명    | 전자적 방식으로 서명 의사를 남기는 것         |
| 디지털 서명  | 공개키 암호 기반의 강한 전자서명 기술         |
| 인증서/PKI | 공개키가 누구의 것인지 보증하는 체계          |

## 단계별 이해
### Step1. 비밀번호 해시와 salt
- 어디에서든 비밀번호를 원문 그대로 저장하면 탈취했을 때 매우 위험해짐.
- 예를 들어 DB에 `user_id : will0w \ password : a1b2c34`처럼 저장되어 있다면 이를 탈취하기만 해도 굉장히 위험함.
- 그래서 비밀번호는 원본 역추적이 불가능한 **해시**를 사용함.
- 해시는 원문 데이터를 고정 길이의 값으로 변환하는 일방향 함수임.
- 다만, 동일한 비밀번호에선 항상 같은 해시가 출력되기에 `salt`라는 임의의 값을 붙여 복잡하게 만듦.
### Step2. 무결성 확인
- 예를 들어 `will0w`의 이번 달 임금이 `300만 원`으로 되어 있다고 가정.
- 데이터를 송신할 때 해시화하여 전달하는데, 이때 값이 조금이라도 바뀌면 해시값이 완전히 변하기에 해시는 **무결성** 검증의 핵심 도구가 됨.
- 하지만 변조된 문서에 새 해시값을 다시 계산해 넣으면 단순 해시 검증을 통과할 수 있어 **서명**이 필요함.
### Step3. 디지털 서명 (w. 개인 키)
- 디지털 서명의 구조는 다음과 같음.
```plain
문서 → 해시 → 개인 키 서명 → 서명 값 생성
```
- `will0w`가 계약서에 서명한다고 가정.
```plain
// 서명 과정
will0w의 계약서
h = hash(will0w의 계약서)
signature = sign(will0w 개인 키, h)

▶ 계약서 원문, 서명 값, will0w의 공개 키 또는 인증서가 남음.

// 검증 과정
h = hash(will0w의 계약서)
verify(will0w 공개 키, h, signature)
```
- 해당 과정을 통해 문서의 무결성 및 인증, 부인 방지까지 보장할 수 있음.
### Step4. 인증서와 PKI
- 이러한 디지털 서명은 공개 키로 검증하지만, 공개 키가 정말 `will0w`의 것인지도 확인해야 함.
- 이를 검증하는 것이 바로 인증서와 PKI.
- 인증서는 특정 공개 키가 특정 사용자에게 속한다는 인증기관 보장 전자 정보.
- PKI는 공개 키 기반 구조라는 의미로 인증서와 함께 사용됨.

## 정리
- 전자 서명은 서명자의 신원과 서명 사실을 증명하고, 변조되지 않았음을 보장하기 위한 기술.
- 비밀번호 해시와 salt를 통해 비밀번호를 보호하고, 디지털 서명에서는 이에 더해 서명자의 개인 키로 서명하여 무결성과 인증까지 보장함.
- 검증자는 공개 키와 인증서/PKI를 이용해 서명이 유효한지 확인하며, 이를 통해 무결성 인증, 부인 방지 제공.
