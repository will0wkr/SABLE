# 보안 스터디 : SONAGI SABLE repository

이 저장소는 보안 스터디 **SONAGI SABLE**의 학습 내용과 과제를 정리하는 공간이다.  
암호학을 중심으로 보안의 기본 개념을 공부하고, 자료 조사와 코드 구현을 함께 진행한다.

## 스터디 목표
- 암호학을 통해 보안의 전반적인 이해도를 높인다.
- 개념만 익히는 데 그치지 않고, 직접 구현하며 학습한다.
- 매주 과제를 진행하고 개인 GitHub에 업로드하며 학습 내용을 기록한다.

## 진행 방식
- 주차별로 하나의 주제를 정해 공부한다.
- 각 개념의 정의, 실제 사용 예시, 개념 간의 관계를 조사한다.
- 간단한 코드로 직접 구현해 보며 이해한다.
- 학습한 내용은 문서와 코드로 정리한다.
