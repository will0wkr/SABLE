# SABLE

보안 스터디 SABLE 레포지토리이다.  
암호학의 핵심 개념을 조사하고, C 언어 기반 예제 코드를 직접 구현하며 학습한다.

## Study Goal
- 암호학의 기본 개념부터 주요 기법까지 단계적으로 학습한다.
- 조사 내용과 코드 구현 결과를 함께 정리한다.
- 단순 이론 암기가 아니라, 직접 설명하고 구현할 수 있는 수준을 목표로 한다.

## How We Study
- 매주 하나의 주제를 선정한다.
- 개념 조사 및 정리를 진행한다.
- 배운 범위 안에서 간단한 코드 예제를 구현한다.
- 결과를 GitHub에 문서와 코드 형태로 기록한다.
