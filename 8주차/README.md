# RSA 암호
- 공개 키는 암호화에, 개인 키는 복호화에 쓰임.
- RSA는 공개 키 암호 방식.
- 두 소수를 곱하는 건 쉽지만 그 곱을 다시 소수로 바꾸는 건 매우 어려움.
- RSA 암호화는 거대(수백수천 비트) 소수의 곱을 이용해 암호화 진행.

# RSA 구조
## 소수
- 소수는 1과 자신만을 약수로 가지는 수로, RSA에선 두 개의 큰 소수 `p`, `q` 선별.
- 이후 이 둘을 곱해 `n`을 만들고, 공개 키에 넣음.
```
p = decimal_1
q = decimal_2

n = p x q
``` 
## 모듈러 연산
- 모듈러 연산은 나머지 연산임.
```math
17 mod 5 = 2
```
- RSA 계산 결과가 매우 크기 때문에 `mod n`을 붙여 범위를 제한함.
```math
C = M(원본)^e(공개 지수)  mod n
```
## 키 생성
- 위에서 말한 것처럼 `n`을 구성하고 오일러 피 함수 `φ(n)` 계산.
```math
φ(n) = (p - 1)(q - 1)
```
- 해당 값을 가지고 개인 키를 만듦.
- 공개 지수 `e`를 해당 값과 서로소가 되도록 구성하여야 함.
- 이후 개인 지수 `d`를 구해야 하며, 다음 조건을 만족해야 함.
```math
e × d ≡ 1 mod φ(n)
```
- `d`는 `e`의 모듈러 역원.
## 공개 키와 개인 키
### 공개 키
- `(n, e)`로 구성.
- 누구에게나 공개 가능.
- 암호화에 이용.
### 개인 키
- `(n, d)`로 구성.
- 개인만 알고 있어야 함.
- 복호화에 이용.
## 암·복호화
### 암호화
- 원본 M, 암호문 C라고 할 때
```math
C = M^e mod n
```
### 복호화
```math
M = C^d mod n
```

# RSA 안전성
## 보안 원리
- 공격자는 공개 키를 알 수 있음. 
- 하지만 개인키 `d`를 구하려면 `φ(n)`를 알아야 하고, 이를 알기 위해선 다시 `p`, `q`를 알아야 함.
- `n`을 직접 소인수분해 해 값을 찾아야 하는 것.
- 하지만 실제 RSA의 값은 매우 크기 때문에 소인수분해가 매우 어려움.
